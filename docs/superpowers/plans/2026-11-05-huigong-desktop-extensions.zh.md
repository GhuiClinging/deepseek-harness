# 辉总后宫智囊团桌面扩展实施计划

English | [中文](2026-11-05-huigong-desktop-extensions.md)

> 面向代理执行者：使用 superpowers:executing-plans 在当前会话持续实施。

**目标：** 交付包含可见浏览器入口、源码角色、内置 IM 集成和本机头像昵称的 macOS ARM64 本地测试安装包。

**架构：** Electron 持有当前带认证的浏览器启动地址。现有设置插件通过注册槽位提供侧栏入口和本机资料编辑器，通过 Host 设置持久化资料字段。品牌描述文件选择包内角色和第三方插件确切版本；安装包运行时携带其依赖闭包。

**技术栈：** 沿用 Electron、TypeScript、Cordis、React、Schemastery、pnpm 和 electron-builder。

**规格：** 用户已确认侧栏浏览器入口、以源码为准的角色及内置 `@xmanrui/dsh-im@5.10.0`；随后选择先做本机头像昵称，远程登录留待后续。

## 全局约束

- 保留现有 profile、凭据、聊天、用户插件及原有角色文件。
- 保持上游账号、遥测和更新策略；远程登录、短信和微信 OAuth 不在本次实现范围内。
- 新增产品文案使用类型化字典，复用现有槽位和基础组件。
- 不发布、不推送、不提交、不修改密钥或证书，不在任务未安全停止时替换正在运行的安装版应用。
- 在 `feat/huigong-desktop` 继续实施；本次改动依赖该分支已有的未提交品牌实现。

## 审查重点

- Host 重启后旧浏览器链接失效；界面不接收认证 Token。
- 包内角色忽略旧的或无效的本地角色内容，且不覆盖文件。
- 全新数据目录中内置 IM 依赖可离线加载，已有安装只激活一次。
- 显式禁用的内置插件在后续启动与恢复时保持禁用。
- 本机头像输入有大小限制且仅接受图片；桌面与网页可观察持久化资料变化。
